# 四模型回答数据交付

这份数据来自 Compressed-CoT 替换模型实验，快照日期为 2026-10-20。
数据提交在 `ZZY` 分支。

## 下载与使用

1. 下载 [完整数据压缩包（约 87 MB）](四模型回答数据_20261020.zip)。
2. 解压后先阅读 [中文交付说明](先读我_交付说明.txt)。
3. Excel/WPS 查看 `便于清洗/全部回答.csv`；程序处理使用 `便于清洗/全部回答.jsonl`。
4. 优先复核 `便于清洗/待复核回答_请在副本填写.csv`，保留原始数据副本。

安装 Python 后，也可以在下载目录运行：

```bash
python -m zipfile -e 四模型回答数据_20261020.zip .
python 四模型回答数据_20261020/校验交付包.py
```

## 数据规模

| 模型 | 保存的回答数 | 待复核数 |
|---|---:|---:|
| DeepSeek（deepseek-flash） | 18,600 | 797 |
| Qwen2.5-7B-Instruct | 18,600 | 709 |
| Qwen3-8B | 18,600 | 987 |
| Hy4-preview | 18,600 | 1,427 |
| 合计 | 74,400 | 3,920 |

每个模型使用相同的 3 个数据集（MMLU-Pro 数学、GSM8K、MATH500），
每个数据集 200 道题、31 种提示词。共有 600 道不同题目。
`temperature=0`、最大输出 800 tokens、数据抽样种子为 91。
这是每数据集 200 题的替换模型实验。

压缩包包含原始回答 JSON、题目和标准答案、提示词、逐题 CSV/JSONL、
已有评分修订记录、待复核清单、统计图表和评分参考代码。
具体版本与配置见 [数据概况](数据概况.json) 及各模型的 `manifest.json`。

## 清洗时保留的信息

- `status=ok` 表示请求成功，不表示答案正确。
- 待复核清单包括截断和答案提取等问题，不能将其全部当作错误或删除。
- 保留题目、提示词和模型标识，保留原始回答及 API 返回的 token 数。
- 评分修改应单独记录旧值、新值、理由、复核者和时间。
- DeepSeek 已有离线重评分记录；统一评分口径时，应核对四个实验的版本与修订来源。
- 修改评分后应重新统计和绘图；现有图表对应交付时的评分。

本次交付只复制和导出已有结果，没有新增模型调用或重新评分。
包内未包含 API 密钥、本机登录配置或未完成的 Kimi 数据。
