# dataAnalysis-vision

题目 2 的资料读取实验交付在 [`experiments/lost-in-the-middle/`](experiments/lost-in-the-middle/)。包含 benchmark 和抽题说明、31 条 prompt 策略、完整测试输入、两个免费模型的 **74,800 条原始回答**、最终自动评分、模型输出示例和六组可重绘图表。

当前交付位于 `fwl` 分支，采集于北京时间 **2026-10-22 20:21** 完成。原始数据压缩后使用 Git LFS 保存；克隆后执行 `git lfs install` 和 `git lfs pull`。结论为部分复现位置效应，未在两个模型上稳定复现完整 U 形。完整入口见实验目录的 [README](experiments/lost-in-the-middle/README.md)。
