这组文档讲述原五项实验。演示新版代码反馈或主页面总数时，以[当前数据口径](../README.md#data)和独立补充批次为准。

老师另要求 **5–6 分钟、1080P 的汇报视频**。需要小组实际操作当前系统、讲解发现并说明局限；成片和实际提交位置由小组补齐。录制顺序见[演示指南](../docs/demo-guide.md)和[时间建议](../docs/submission.md)。

仓库已移除旧自动合成的幻灯片视频、字幕和生成元数据，避免误认作实际系统演示。重新生成 PDF 可运行 `python3 scripts/delivery/build_course_documents.py`。
