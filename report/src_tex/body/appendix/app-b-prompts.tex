\section{多轮代码修复六种反馈臂协议与多文档拼装规范}

在代码修复补充实验（\texttt{experiments/code\_repair\_v2/}）中，除 \texttt{resample} 仅重传原始函数题目外，其余五种沿着历史版本迭代的处理臂统一采用后缀指令：“\emph{Review your previous implementation against the original task. Correct any correctness issue you find; otherwise preserve the working implementation. Return the complete implementation in one Python code block, including required imports. Preserve the specified interface.}”各处理臂前置注入的诊断 JSON 字段权限严格按表~\ref{tab:app-b-arms} 执行白名单投影，物理隔绝隐藏保留集。
