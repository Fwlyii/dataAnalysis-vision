# 课程报告 LaTeX 源码

主文件为 `tjumain.tex`。正文保留六个一级部分（实验目的、小组分工、项目介绍、实验过程、实验结论、实验体会），附录 A 至 I 分门别类收纳数据字典与质量审计、提示策略与实验配置、核心源码清单、典型原始问答与代码修复 Diff 档案、系统多终端实测截图、全维度统计查阅表、工程架构与 44 幅图册索引、课程评分核验记录及衍生科学图册代表性矢量图版。

## 编译方式

需要安装 TeX Live（含 `xelatex`、`xdvipdfmx`、`ctex`、`xecjk`、`fandol`、`newtx` 等宏包）。在 `report/src_tex/` 目录下运行：

```sh
sh build.sh
```

脚本将编译三遍以刷新目录、图表索引与交叉引用，最终输出至 `report/课程报告.pdf`。
