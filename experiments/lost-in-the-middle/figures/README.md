## 画图契约与过滤规则

后端为 Python/matplotlib，版型为定量分面或矩阵，PNG/SVG/PDF 同步输出，不使用三维透视。分类比较使用点和区间，不用连接无序策略的折线；比例轴从 0 起。模型用 Okabe-Ito 色系并配合不同点形；热力图使用 cividis，共享色标。

全部 74,800 条在最终评分表中。主实验 74,400 条，其中主比较 english19=45,600 条；其余中文 12,000、格式压力 7,200、极短预算 9,600 条具有评分偏差，分别保留于 scores/strategies。无资料对照 400 条单独报告。图 01–05 明确使用 english19，图 06 使用主实验全部 31 策略。未因答错或截断而排除任何行。

95% 区间重采样独立 question_id，5,000 次、种子 91。绝对准确率图先求每题的组内平均再抽题；所有组平衡，因此与逐条平均相同。位置差图采用固定题、策略、资料数后的配对差。所有区间为探索性，未做多重比较校正。热力图、散点和截断比例仅作描述，不附推断结论。

## 重新生成

从仓库根目录：

```bash
python experiments/lost-in-the-middle/src/plot_results.py
```

若需要进一步展示逐题差异，可从 scores.csv 按题聚合画配对点图；若分析中文组，需要先建立翻译别名表并保留人工复核记录。现有数据都是独立单轮资料读取，不适合画对话轮次或实时检索调用次数。
