# 项目概述

## 研究目标

研究**输出表达、证据组织和执行反馈如何影响大模型的任务表现**。任务覆盖数学/选择题、文档问答和Python代码。数据、评分、统计与图形在同一仓库中可追溯。

## 实验设计

| 实验 | 主要变量 | 数据规模 |
|---|---|---:|
| 推理提示实验 | 模型、题库、语言与31种提示策略 | 600题，74,400条回答 |
| 文档问答实验 | 模型、提示、文档数、证据位置 | 200题，74,800条回答 |
| 代码生成实验 | 三模型、31种提示、5次独立采样 | 194题，90,210条回答 |
| 文档位置实验 | 两模型、20篇文档、9个证据位置 | 200题，3,600条回答 |
| 代码修复实验 | 两模型、四种处理、初稿与四轮修改 | 164题，5,576条回答 |

共**248,586条物理响应**。文档位置实验复用文档问答的问题；代码修复的共享初稿只计一次。代码生成有1题因评测环境排除，465条记录保留为空评分，其余89,745条进入性能统计。

## 主要结论

| 发现 | 课程类别 | 证据 |
|---|---|---|
| 分步解题的高分可以用简洁表达保留 | 低维1 | Qwen2.5/GSM8K：只给答案22.0%，分步91.5%，简洁分步92.0%；后两者Token减少21.5%。17组跨任务对照全部缩短输出，15组得分点估计不降 |
| 中文作答模板在MATH500上帮助多数模型省Token、提分 | 低维2 | 四模型全部缩短，三模型提分；Qwen3为58.0%→69.5% |
| 极端限长引发输出反弹 | 异常/特殊现象 | 词数上限10→1，12组中9组实际输出增加；DeepSeek/MATH500的字母数100→10，Token为102.0→520.6、得分83.5%→38.0% |
| 模型优势取决于证据位置 | 多维1：模型×位置→命中率 | Qwen3相对Qwen2.5的首位优势16.5 pp、末位2.5 pp；首尾模型增益差14.0 pp，区间[5.5,23.0] |
| 具体执行反例比笼统检查更有效地推动代码修复 | 多维2：反馈×轮次→通过率 | Qwen3第四轮具体反例组141/164、自检129/164；差7.32 pp，区间[3.05,12.20] |

完整证据与解释见 `reports/story/findings.md`、`reports/document_positions/findings.md`、`reports/code_repair/课设展示结论.md`。中文模板的提分发现定位于MATH500；独立采样与多轮反馈分别解释，任务评分不混合。

## 数据与代码

| 材料 | 目录与入口 |
|---|---|
| 数据采集 | `scripts/acquisition/`：推理、文档问答、代码生成、文档位置、代码修复 |
| 原始数据 | `data/raw/`：原始ZIP、JSONL、场景、题库、源评分与执行记录；原字节冻结，外层按内容命名 |
| 数据清洗 | `scripts/cleaning/`：唯一键、类型、时间、缺失、源评分连接和匿名特征 |
| 清洗数据 | `data/processed/`：五类逐条表、题目/提示、修复事件、248,586行统一匿名特征 |
| 数据分析 | `scripts/analysis/`与`experiments/*/src/analyze*.py`：配对比较、题目聚类区间、Prompt差异、位置关系、错误与修复 |
| 绘图与系统 | `scripts/figures/`、`scripts/system/`、`app/`：可编辑SVG、课程图表库与五章交互 |
| 报告与答辩 | `report/case_report.pdf`、`presentation/defense_slides.pdf`及演示制作源码 |
| 课程最终提交 | 人工录制并提交一个演示视频；仓库不存放成片 |

数据字典：`data/data_dictionary.md`。原始校验：`data/inventory/raw_files.json`。质量与缺失：`data/quality/`。原研究资料登记快照：`data/inventory/current_files.json`；该文件作为来源记录保留，不作为当前仓库目录索引。

清洗保留源评分与重复条件，缺失不补0，环境排除不算模型失败。CSV空单元格为null、布尔为true/false、时间为UTC。匿名特征用metric_name区分评分，不计算跨任务总准确率。

## 使用方法

```bash
# 标准库启动网页
python3 app/launch.py --port 8766

# 从匿名特征复算五类实验的条件统计
python3 scripts/reproduce_anonymous.py

# 查看完整离线流程
python3 scripts/pipeline.py all --plan

# 最终演示视频由人工录制并提交，不生成重复源码提交包
```

完整清洗、分析与重绘需`requirements/analysis.txt`；文档生成另需`requirements/documents.txt`。图字使用Times New Roman，文档中文字体可用`COURSE_CJK_FONT_FILE`指定。采集入口默认计划/干跑，只有主动加`--execute`才请求模型；离线流程只读取保存材料。

完整研究资料保留原始来源与来源映射；网页使用匿名数值特征、统计、图稿和已允许展示的示例。最终人工录制并提交演示视频。第三方来源、协议和评分适用范围见对应实验说明。
