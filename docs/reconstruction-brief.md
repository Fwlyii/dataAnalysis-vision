# 知微研究内容与图表重构

本轮负责中文故事结构、科研图表、数据处理演示、匿名记录与导出；页面动效由团队继续完善。用户已确认五个一级模块，研究问题与核心发现各有总分关系，核心发现固定为四总体与三专项。

界面用于课堂阅读与数据探索。延用知微品牌，内容区以浅纸色、墨蓝、青绿和陶土色呈现；科研SVG使用同一色系、清楚中文、真实坐标和直接标注。页面保持轻量原生HTML/CSS/JS，图表与故事数据分离，便于后续交接。

五模块：研究问题、采集设计、数据处理、核心发现、总结与反思。四总体：Token-log边际收益、模型规模、简洁表达、限长反弹；三专项：中文数学、证据位置、执行反馈。图表库在同一主系统内挂载，兼容旧探索地址。

数据、统计、评分和受保护的科学图稿不修改。新增SVG图册读取冻结证据生成，包含目录与逐图数值。未知规模保持未知；log拟合保留模型和任务范围。

答辩版恢复原知微五气泡首页，去除左侧重复目录、跨章CTA和逐图工具，只保留五章顶导航。三任务与31策略直接显示，清洗为A/B/C/D完整静态Figure；核心发现七主题37图在同一长页面，上下滚动阅读。完整图稿与交互探索保留在独立资源路由，主展示不另设入口。

首页：`app/src/research-home.js`。主壳：`app/src/research.js`。叙事与清洗：`research-content.js`。探索与记录：`research-explorer.js`。专项记录：`research-special-records.js`。独立SVG：`scripts/figures/build_research_atlas.py`。
