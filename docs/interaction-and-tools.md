# 交互与工具：课设对照

依据 [课设题目二](assignment/数据分析和可视化-题目2.pdf) 第 1、5、6、8 页。工具列表提供可选择的实现方式；本系统为各工具安排了实际功能，页面不显示框架宣传文字。

Vega-Lite 的 interval selection 表示数据范围查询，Vega View 的 signal listener 将范围传给其他视图；参见 [选择参数](https://vega.github.io/vega-lite/docs/selection.html) 和 [View API](https://vega.github.io/vega/docs/api/view/)。D3 的 transition 和 interrupt 用于可打断的绘图揭示，参见 [官方说明](https://d3js.org/d3-transition)。Plotly 接收本项目已计算的 Q1、median、Q3 和须，不重新定义分位数；参见 [箱线图](https://plotly.com/javascript/box-plots/) 和 [函数接口](https://plotly.com/javascript/plotlyjs-function-reference/)。

四个新增前端包共约 2.45 MB，均以固定版本本地保存，按视图需要加载。来源、SHA-256 与许可证在 `app/assets/vendor/visualization-libraries.json`。构建检查每个包的哈希和许可证文件。运行不请求 CDN、模型 API 或原始回答文件。

## 核心交互与数据集合

### 散点 → 错误率 → 评分记录

散点为 93 个模型×Prompt 条件，每个条件来自相同的 193 道可评题和五次独立结果，共 965 条。横轴是平均返回 token，纵轴是当前 Pass@1/3/5，颜色和形状为模型。

拖动框选后，按数据坐标筛选条件。右侧错误图、条件数、回答数、平均 Pass@k、发现说明和记录入口同时使用这个条件集合。错误图分母为所选条件的全部可评回答；错误柱可继续筛选该错误类别。没有选中点时显示 0 个条件，不恢复成全部条件。CSV 仅导出当前集合。

范围写入 `codeBrush=xmin,xmax,ymin,ymax`，刷新可恢复。切换 Pass 指标时清除范围，避免把旧指标坐标套到新指标。双击或“清除框选”恢复全部。精确范围表单提供键盘路径，错误类型下拉与按钮提供错误柱的键盘替代。

所选条件的平均 Pass@k 是各条件估计的均值；193 道题在模型/Prompt 下重复，不能将“条件数×题数”称为独立题目数量。交互选择属于探索性分析，没有据此计算确认性区间或因果效应。

### 五次独立采样播放

默认显示全部五点。点击播放或拖动整数滑块，依次揭示真实的 k=1…5 估计；左侧曲线与区间、右侧观测新增、当前数值、说明和 URL 同步。没有新增或平滑生成的数据点。Pass@k 仍从全部五次保存结果计算；播放不是实时生成，也不是反馈修复。

播放可暂停并继续，到第 5 次停止。进入详情、切换视图、页面隐藏或控制行离开视口时停止；再次渲染时释放定时器、过渡、监听器和图形实例。静态 SVG 导出保留当前揭示状态；输出开销导出包含当前散点、错误图、筛选摘要和来源。

### 分布缩放与记录

Plotly 箱线图使用源匿名响应的真实 token；Q1/Q3 为线性分位数，须为 1.5 IQR 范围内的最远观测，与先前口径相同。不绘制原始全文或个人标识。拖动改变坐标视窗，双击复位；点击箱体定位模型×任务，点击图例定位模型；上方原生筛选和“查看筛选记录”为键盘替代。坐标缩放不改变上方筛选定义的记录集合。

## 动效规则

2026-11-01 新增的独立 `app/src/interaction.js` / `app/interaction.css` 为逐页交互层，复用本地 Motion mini。三方向卡、五实验卡、四流程节点分别展开原研究内容；研究页、图表库 13 图形、四代码子视图、五项更多发现各有对应的转场与操作导览。聚焦图表只改变外围阅读材料的强调，不替换或重新计算图形。核心发现的新增按钮整合进原图表工具栏，保留首屏科学图的位置与大小。

新增点击反馈约240ms、图面揭示约480ms、分面错开不超过160ms。动画可打断，结束后恢复原行内样式；减少动态时保留展开、选择与聚焦操作。详情继续使用原窗口；科研 SVG 内不写入反馈标记，导出仍由原控制器负责。完整覆盖与复现方式见[前端维护流程](visual-refinement-workflow.md)和[检查说明](web-checks.md)。下列规则中的采样播放、错误柱与科学条件更新指原图组件内部逻辑。

- 唯一的连续演示序列为五次采样，默认不自动播放。
- 采样揭示 260 ms，错误柱更新 220 ms，条件切换 180 ms；不使用弹跳、装饰性循环或滚动入场。
- 尊重 `prefers-reduced-motion`：保持离散步骤、选区、数值与高亮，取消空间补间及渐变过渡。
- 跨视图模型颜色统一：DeepSeek 蓝、Qwen2.5 紫、Qwen3 绿、HY4 橙；提示类型的颜色由独立图例说明。
