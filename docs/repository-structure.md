# 仓库结构与整理说明

[← 项目首页](../README.md#layout) · [课程验收](../guide/README.md) · [文档索引](README.md)

仓库根目录就是课程系统组的源码交付入口，核心为 `app/`、`data/`、`report/`、`presentation/`；老师原要求统一放在 `guide/`。

| 目录 | 用途 |
|---|---|
| `app/` | 当前五球入口、五屏、补充图册、现用素材和匿名研究快照 |
| `data/` | 原始材料、清洗数据、字段、质量与来源清单 |
| `report/` | 案例报告 PDF、正文与生成校验 |
| `presentation/` | 12 页答辩 PDF、讲稿和内容源 |
| `guide/` | 课程要求原文和逐项对照 |
| `scripts/`、`experiments/`、`configs/`、`requirements/` | 采集、清洗、统计、绘图、构建与复现依赖 |
| `reports/` | 已有批次的统计结果和图形证据，与阅读版 `report/` 分工不同 |
| `docs/`、`tests/` | 方法、设计、演示、部署和自动检查 |

## 清理范围（2026-11-20）

- 删除 Git 中 976 个旧 `submission/` 副本文件；该目录本来就是生成目录，继续由忽略规则排除。
- 删除根目录重复的产品、项目概述及旧版视觉说明，当前说明集中到 README 和 `docs/`。
- 课程 PDF 统一以 `guide/` 为维护来源；构建到网站的 PDF 是面向访问者的材料副本。
- 删除旧自动视频、字幕、元数据及过时的重复交付生成器。
- 发布和验证统一围绕本仓库 `main`，取消对独立旧预览分支的依赖。

1,100 项科研保护文件、原始实验、评分、统计表、图稿和许可证不在本次删除范围。历史整理前的材料可以从 Git 记录查看。

## 不提交的生成内容

`app/dist/`、`app/runtime/`、`artifacts/`、`build/`、`submission/`、`node_modules/`、Python 缓存和个人录屏均通过忽略规则排除。分析会在本地生成新的结果目录，发布前应检查 `git status`，避免将重复副本或凭据加入版本管理。
