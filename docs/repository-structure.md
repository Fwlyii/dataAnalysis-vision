# 仓库结构

项目只有一个运行源码基底：`app/`。研究数据与统计结果分开存放，自动生成物不进入版本管理。

| 目录 | 保留内容 | 使用场景 |
|---|---|---|
| `app/` | 当前源码、现用素材、匿名数据快照 | 修改与运行网站 |
| `data/` | raw、processed、quality、inventory及字段说明 | 研究来源与复现 |
| `reports/` | 聚合CSV、区间、研究结论和科学图稿 | 核对科研数值 |
| `experiments/` / `configs/` | 专项实验实现和协议 | 复现实验 |
| `scripts/` | 按采集、清洗、分析、绘图、构建、文档生成组织 | 离线处理与维护 |
| `tests/` | 当前浏览器检查、小型科学/导出基线及源码保护清单 | 发布与回归 |
| `docs/` | 操作、研究方法、部署、维护和素材来源 | 查阅说明 |
| `report/` | 参考报告PDF、文稿和生成信息 | 录制准备 |
| `presentation/` | 参考PPT PDF、讲稿和内容源 | 录制准备 |
| `requirements/` | 按阶段划分的Python依赖 | 研究与文档环境 |

`app/dist/`、`app/runtime/`、`artifacts/` 和 `node_modules/` 可重新生成并已忽略。最终课程只人工提交一个录制视频，成片不存入仓库。

历次优化目录、截图/录屏、重复提交目录和旧预览缓存已清理。此前记录仍在Git历史；本次没有改写历史或删除Git凭据。若需查看历史材料，可查询整理前提交 `c3d648a`。
