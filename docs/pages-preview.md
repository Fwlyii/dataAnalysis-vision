# 系统访问与章节直达

[← 项目首页](../README.md) · [部署说明](github-pages.md)

本仓库的 Pages 地址为 <https://fwlyii.github.io/dataAnalysis-vision/>，启用并部署成功后可使用以下路径：

| 页面 | 相对站点根目录的路径 |
|---|---|
| 五球入口 | `/` 或 `/#gateway` |
| 研究问题 | `/#s1` |
| 实验设计 | `/#s2` |
| 数据处理 | `/#s3` |
| 核心发现 | `/#s4` |
| 结论、局限与课程材料 | `/#s5` |
| 完整历史图册 | `/legacy.html?chapter=atlas` |
| 课程 PDF | `/data/course-assignment.pdf` |
| 案例报告 | `/data/case-report.pdf` |
| 答辩 PPT | `/data/defense-slides.pdf` |

本地服务使用相同路径，例如 <http://127.0.0.1:8770/#s4>。旧独立预览分支已不参与当前发布；该说明统一指向本仓库的 `main`。
