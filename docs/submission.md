# 课程提交与人工演示

[← 项目首页](../README.md) · [老师要求](../guide/README.md) · [演示路线](demo-guide.md)

本项目按“系统组”提交 **可运行系统、代码仓库、数据说明、案例报告及答辩材料**。课程 PDF 另要求一份 **5–6 分钟、1080P 的汇报视频**，PPT 建议 8–12 页。

## 提交清单

1. 从 `main` 取得完整仓库，将外层文件夹按实际信息命名为 `学号_姓名_AI对话行为分析_系统`。
2. 确认根目录保留 `README.md`、`app/`、`data/`、`report/` 与 `presentation/`；研究脚本及依赖一起提供。
3. 阅读[大文件下载说明](../data/DOWNLOAD.md#download)。需要复算时下载对应 LFS 对象；不随提交提供完整原始材料时，保留仓库地址、来源与校验说明。
4. 在新终端执行 `python3 app/launch.py --port 8770`，确认字体、数据、五球、五屏和案例均可访问。
5. 检查[案例报告 PDF](../report/case_report.pdf)与[答辩 PPT PDF](../presentation/defense_slides.pdf)。两份文件讲解原五项实验；演示补充批次时明确使用当前页面的独立统计口径。
6. 录制实际系统讲解，确认时长、分辨率、音画同步和字幕可读。视频在学校要求的位置提交，并提供实际位置或下载说明。
7. 填写真实组员信息与实际分工，核对[AI 辅助使用说明](collection-and-ai-use.md)，确保组员能解释实现和结论。

仓库不将自动合成的旧幻灯片视频作为最终系统演示；本次整理已移除该产物及重复提交包。源代码只有根目录这一份。

## 建议的 5–6 分钟演示

| 时间 | 内容 |
|---|---|
| 0:00–0:35 | 研究目标、三类任务和五球入口 |
| 0:35–1:20 | 实验设计、字段映射、匿名化和质量规则 |
| 1:20–3:40 | 五项发现，现场演示模型/题库/位置/反馈切换 |
| 3:40–4:40 | 一个真实代码修复案例，解释差异和测试口径 |
| 4:40–5:30 | 局限、复算与材料入口 |

可用 `python3 scripts/system/check_coursework.py` 核对结构和文档链接；完整测试见[测试说明](../tests/README.md)。
