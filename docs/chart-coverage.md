五个正式发现及维度证据见 [结论核对](insight-audit.md)与[案例报告](../report/case_report.pdf)。两条低维、两条多维、一条异常均有图形和统计支持。选项 B 要求至少三个核心交互视图与一种有效联动；当前五案例、自由探索及分类矩阵均有实际入口。

主入口另有三个任务的预算–SR 分面（每模型 93 个实测提示点）、31 提示 × 3 位置 × 2 模型的矩阵，以及按文档数分面的真实位置剖面。主图由 Matplotlib 生成 SVG；探索库采用 SVG renderer。

位置矩阵每格包含同模型、同提示、同支持位置的 400 次响应，来自 200 道题×10/20 两文档条件。格子→匿名记录→联动探索→刷新页面保持原集合 400 行，模型/提示/位置上下文可见；“清除位置筛选”可明确返回更宽范围，避免联动时默默扩大样本。图表切换也保留共享筛选。

任务标签统一为 GSM8K 算术应用题、MATH500 竞赛数学、MMLU-Pro 选择题和 NQ-Open 文档问答。MMLU-Pro 源说明称数学子集，但保留的题目没有学科元数据，当前不把学科视为已核实。分类、计数代理、评分重放与缺失说明见 [方法](methodology.md)；源规则加已有 139 条覆盖的 100% 复现不等于人类语义审核，170 条抽样仍待人审。

## 交互增强对应

- 代码开销：Vega-Lite 二维框选 → 条件统计/错误率 → 对应匿名评分；源条件与记录集合保持一致。
- 代码采样：D3 依次揭示 1–5 个真实估计，数值、说明、右侧新增和 URL 同步，支持暂停及键盘滑块。
- 分组箱线：Plotly 的 SVG 分布图，缩放/复位、箱体/图例→记录及原生筛选入口。
- ECharts 现启用短反馈动画；动态视图均有减少动态效果路径。详细版本、工具选择与课程条款见 [交互说明](interaction-and-tools.md)。
