# 模型行为研究系统

服务课设课堂展示与模型行为研究。研究问题为：输出表达、证据组织和执行反馈如何影响任务表现。

任务包括推理/选择题、文档问答、Python代码生成与修复。五章主页展示简洁作答、中文数学、限长反弹、资料位置和反馈修复；完整图表库提供课程视图与联动探索。

输入为冻结原始记录和保存评分；清洗与数值统计不覆盖原始数据，不混合任务评分，不重复计数修复初稿。前端使用本地资源与可编辑SVG，标准库即可启动。

根目录按课程系统组结构保存源码、数据、报告和答辩材料，网页使用匿名研究快照。数据下载和当前统计口径见 [数据说明](../data/DOWNLOAD.md)，教师验收入口见 [课程对照](../guide/README.md)。
