## 回答数量

新主页面选用五组实验，展示 `248586 − 5576 + 24600 = 267610` 份物理回答。原 Mini 修复批 5,576 份另作历史复核；仓库累计仍为 `248586 + 24600 = 273186`，不是独立题目数。原统一表和新补充 21 列表分开保存，没有拼接覆盖。

补充代码反馈批次按共享初稿计数：`164 × 2 × 3 × (1 + 6 × 4) = 24600`。六条策略复用初稿，不能按六条五版本轨迹重复计入初稿。

## 新增简洁代码区间

图版 III 的三组代码生成区间由 `scripts/analysis/derive_concise_ci.py` 从冻结的 90,210 条匿名特征计算。排除环境不可比记录与 T149，按 193 道共同题目聚类，5,000 次 bootstrap，Python RNG seed 91；比较简洁分步与默认分步，每题每策略五份独立生成。复算值与前端 `CODE_CONCISE_CI` 一致。

代码反馈的完整通过同时要求公开诊断与保留测试通过；公开测试负责向模型反馈，额外保留输入不进入反馈。
