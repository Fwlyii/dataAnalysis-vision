# 知微展示顺序

运行 `python3 app/launch.py --port 8770` 后，从 `#s1` 开始。桌面放映可使用顶部导航和浏览器支持时出现的全屏按钮；核心发现用三页标签切换。

1. **研究问题**：说明交互策略如何影响质量与开销，再展开数学、文档、代码三类任务。用提示策略切片演示同一模型在三个题库中的条件差异。
2. **实验设计**：沿回答组织、语言模板、长度预算、表达格式四维介绍31种实际提示。选择一项，显示发送指令与模型/题库对照；用账本说明本页五组实验选用267,610份响应。
3. **数据处理**：先读两种原始来源中同义异名的字段，再看转换代码、统一记录和21列结构。字段选择用于讲清映射关系。
4. **核心发现第一页**：依次读实际Token与评分的边际收益、模型随题库变化的排序、简洁表达对Token/得分的影响、过紧长度约束的反弹。模型参数按架构及公开口径分别解释。
5. **核心发现第二页**：数学模板固定同题比较；文档固定20篇资料，沿九个实测位置读取两模型及区间。
6. **核心发现第三页**：先读六策略五版轨迹，再看单反例相对自查的配对差异；切换公开诊断/完整测试与模型。按需看终稿区间、修复与回退、Token代价、初稿错误和四个真实案例。
7. **结论与反思**：以五条建议收尾，说明任务范围、自动评分、统计区间、架构和测试覆盖等条件。

每幅图按“横纵轴和单位 → 相同条件的对照 → 关键现象 → 结论范围”讲解。图版的说明和数据表用于回答细节问题。

主页面选用数与仓库总量分开解释：267,610为本页五组实验；仓库累计273,186份原始响应，包含单独保存的5,576份历史Mini批次。补充反馈共享初稿只计一次：`164×2×3×(1+6×4)=24,600`。
