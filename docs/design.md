# 知微 · 景深

当前主展示采用用户确认的 Claude 版本。实现入口为 `app/index.html`、`app/zhiwei.css` 与 `app/src/zhiwei.js`；原始研究数据和已发布图稿沿用冻结快照。

## 开场与五球入口

入口位于 `#gateway`，由 `zhiwei-gate.css` 和 `src/zhiwei-gate.js` 实现。它沿用旧版粒子汇聚、光学透镜和五球分散的开场结构，以深靛蓝为底，五球依次对应紫色研究问题、蓝色实验设计、青色数据处理、品红核心发现、琥珀结论与反思。光球由 CSS 渐变、反光、内部经线与光环绘制，透镜使用 SVG，粒子使用 Canvas，无需位图素材或外部运行依赖。

开场约 3.4 秒，可以跳过或重播。点击光球以扩散转场进入 `#s1`–`#s5`，并恢复所选板块的对焦动画；页内仍按原方式滚动和翻页。左上角“知微”返回入口，浏览器前进、后退及章节深链接保留对应位置。入口显示时正文设为 `inert`，顶部章节导航仍可直接使用。

光球支持 Tab 聚焦、方向键切换、Home/End 与 Enter；Escape 跳过开场或回到上次进入的章节。手机以三球加两球排列，矮屏允许入口自然滚动。减少动态效果偏好下直接显示静态入口并即时跳转，页面隐藏或离开入口时停止粒子循环。

## 视觉结构

页面以显微镜下的景深组织阅读：远景为深靛蓝光场、视野刻度环与微尘，中景为磨砂玻璃图版，前景为跟随当前主展品的取景框。每屏使用不同主光：研究问题偏紫，实验设计偏蓝，处理偏青，发现偏品红，结论偏琥珀。

玻璃图版使用左上高光、渐变细边和下方阴影区分层次。每屏的主要图版更亮；模型名册、清洗规则与局限说明直接放在光场中。

|---|---|
| `--bg` | `#050816`，页面底色 |
| `--glass-fill` | `rgba(9,12,30,.8)`，展板材质 |

CSS 中的变量为当前主界面的样式来源；`.impeccable/design.json` 保留历史深海玻璃组件记录，供兼容图册维护时参考。

## 图表与交互

主图由 `zhiwei.js` 读取四份科研 JSON 后绘制原生 SVG。模型颜色固定为 Qwen2.5 紫、Qwen3 橙、DeepSeek 绿、HY4 品红；顺序色使用紫色亮度，差值使用紫—橙发散色。状态同时使用文本与颜色。

每图保留题库、模型、条件、评分口径、单位与来源。悬停或键盘聚焦显示数值，数据表提供另一种读取方式。置信区间使用误差线或带状区域；截取坐标范围在读图说明中注明。图版III的代码生成区间由保存的逐条特征按题聚类bootstrap复算，脚本为 `scripts/analysis/derive_concise_ci.py`。

代码页保留六策略、五版本轨迹、公开诊断/完整测试切换、配对差异、终稿区间、修复与回退、Token代价、初稿错误和四个真实案例。完整旧图册位于 `legacy.html?chapter=atlas`，保留44张独立图及原探索功能。

## 字体与动态效果

标题使用 `zhiwei-serif.woff2` 的思源宋体子集，许可为 `app/assets/fonts/Noto-CJK-OFL.txt`。正文拉丁字母与数字使用本地Geist，中文正文使用系统黑体。新增字形可回退到系统宋体。

进入板块时以“对焦”过渡组织图版、取景框和数字；模型、题库及指标切换具有短过渡。`prefers-reduced-motion` 下关闭主要入场动画与取景框飞入。键盘焦点保持可见。

## 响应式与核验

宽于1180px且高于700px时采用整屏吸附；窄屏与矮屏转为自然滚动，网格按宽度堆叠。放映按钮仅在浏览器允许全屏时显示。

当前回归入口是 `tests/browser/zhiwei.mjs`，报告写入 `artifacts/qa/zhiwei/report.json`。它核对新主展示的响应式、数值、交互与资源；历史五气泡和紧凑四图板的检查记录对应兼容入口，不作为当前主展示的验收结果。

五球入口单独由 `tests/browser/zhiwei-gate.mjs` 验证，覆盖开场跳过/重播、五条路径、返回入口、历史导航、深链接、键盘操作、减少动态效果及五种视口。结果、截图和无障碍检查写入 `artifacts/qa/zhiwei-gate/`。
